# Диагностика и восстановление приёма

В состоянии tinySA доступны `transactions` и `previous_transactions`: до 64
завершённых попыток текстового обмена текущего и предыдущего соединения. Запись
содержит имя команды без аргументов, UTC начала, срок, длительность, число байтов
и строк, время последнего байта относительно начала и наличие терминатора.
Сырые ответы, спектры, путь порта и текст исключения в журнал не включаются.
`completed` означает завершённый текстовый кадр, не физический readback настройки.
Бинарные обмены этим журналом пока не охвачены.

`POST /api/v1/sessions/{id}/streams/{stream_id}/recover` принимает `{}` и
доступен при `features.explicit_stream_recovery = true`. Он создаёт новое
соединение только для уже остановленного/ошибочного исполнителя. Работающий
прибор или незавершённый graceful stop требуют отдельной явной остановки.
Восстановление не возобновляет watch, фон или lab-аренду. Другой прибор остаётся
у своего исполнителя. Успешный HTTP-ответ означает запуск попытки; свежесть
приёма подтверждается новым сохранённым измерением, а не ответом recover.

Незавершённый старый ответ остаётся препятствием: новый transport сначала
ожидает его терминатор и тихое окно. Поздний `ch>` не может подтвердить следующую
команду. Если терминатор потерян или прибор завис, восстановление заканчивается
ошибкой синхронизации; сброс состояния ядра не выдаётся за починку прибора.
Физическое восстановление после такого отказа отдельно требует проверки.

Это диагностика и безопасная попытка переподключения, не установленная причина
таймаута из `continuous-spectrum-validation.md`. ASCII `scan` остаётся штатным
режимом. Бинарный scanraw испытывается отдельно на закреплённом профиле прошивки.

In macOS, open **Тракт / Наблюдение → Диагностика обмена и восстановление**.
The panel shows bounded metadata for the current and previous connection.
**Восстановить остановленный поток** is available only when the server declares
`explicit_stream_recovery` and the worker is stopped. It does not label old data
as fresh. A new committed measurement must arrive before reception is confirmed.
