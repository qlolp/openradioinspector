# Изоляция событий наблюдения

Обработка события ограничена его версией эталона. При следующем анализе
после замены эталона прежние открытые события получают состояние
`superseded` и ссылку `superseded_by_baseline_id`: это не означает исчезновение
сигнала. Их исходные доказательства и операторский вердикт сохраняются.
Совпадение частот на новой сетке создаёт отдельное событие новой версии.

Разрешённые бины с `watch_changes=false` исключаются до объединения тревог,
включая широкополосные. Исходные изменения по-прежнему исключены из обучения.
Все найденные регионы записываются без предела 32; один свип учитывается
один раз на событие, даже если его область разделилась на несколько пиков.
Списки событий во всех трёх клиентах отображаются отдельно от выбора проекта.
Проверки этих сценариев синтетические; аппаратная проверка не проводилась.
