# Состояние выпуска OpenRadioInspector

Для личной проверки доступны инженерные пакеты настольной версии 0.4.0 и Android Field 0.1.0. Для каждого пакета ниже указаны ревизия исходников и проведённые испытания. Публичный выпуск требует проверки канала установки и испытаний конкретного пакета на целевом устройстве. У Debian amd64 и мобильных клиентов собственные каналы поставки. [Приёмка и публикация по платформам](all-platforms.md) · [Установка пакета](installation.md) · [План 0.4.0](0.4.0.md)

22 ноября административный API подтвердил защиту `main` с 27 обязательными проверками, неизменяемость опубликованных GitHub Releases и девять окружений выпуска с допуском ветки `main`. Контакты поддержки и политики для мобильных магазинов размещены в репозитории. [Защита main](branch-protection.md) · [Поддержка](../field/support.md) · [Конфиденциальность](../field/privacy.md)

#### Условие принятия

Один неизменный UI/core/supervisor/engineering kit должен пройти все обязательные
строки [полного протокола](macos-post-test-comprehensive-acceptance.md): короткий
видимый smoke, faults/ENOSPC, миллионную историю, binary-v1 и SSE по 1800 секунд,
параллельные историю и backup, отдельный restore, восемь реальных часов приборов,
установку/offline/обновление/откат и проверку удобства. Все предложенные источники
входят в знаменатель, включая потерянные и не показанные.

Пороги: UI p95 ≤100 мс; очередь ≤200 мс; commit→фактический показ ≤250 мс;
pan/zoom ≥30 fps; RSS core ≤256 МиБ, UI ≤1 ГиБ, фон ≤1,5 ГиБ.
Неизвестное или невыполненное условие не становится PASS.

Общий публичный выпуск дополнительно требует приёмки Windows/Web/Pi, состава
runtime и лицензий, повторной проверки настроек на момент выпуска и решения по опубликованной истории.
Очистка истории проводится отдельной согласованной операцией с восстановимым
приватным backup; работа над UI её не выполняет.
