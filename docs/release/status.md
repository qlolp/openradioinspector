Версия Python-пакета в исходниках — `0.4.0.dev0`. Цель первой приёмки —
личный `0.4.0-macos.rc.1`. На базе `9154cf5` объединены модернизация ядра,
macOS workbench, восстановление приёма и истории, быстрый проход AR-DV1
и последовательные планы обзора. Сборки и проверки привязываются к своему SHA.

## История подготовки и уборки

В срезе полного tinySA control были реализованы typed settings/jobs, lab-аренда,
live screen, отдельные артефакты, SD/presets/measurements/generator/audio и
панели Web/Windows/macOS. Состав и ограничения:
[tinySA full control](../tinysa-full-control.md). Проверки среза относятся
к его SHA. Для ZS405, LISTEN и RF предусмотрена отдельная аппаратная приёмка.

Локальная проверка tinySA-среза 9 ноября: release runner — **1518 тестов,
0 skips**, семь временных архивов неизменны; реальный Chromium прошёл
synthetic core/HTTP flow (экран480×320, lab, PNG, release). Wheel/sdist и
установка wheel вне checkout проверены. Независимое ревью исправлений
пройдено; Windows/macOS пакеты и native Swift подтверждаются CI, аппаратный
ZS405/LISTEN/RF и восьмичасовой стенд остаются непроверенными.

В этом срезе также исправлена гонка учёта завершившегося Windows Job Object:
runner ограниченно ждёт обновления счётчика после выхода процесса. Живые
дочерние процессы и несовпадение SHA по-прежнему проваливают приёмку.

### Проверки и уборка

- Перед удалением веток создан приватный bundle и восстановлен отдельный mirror;
  `git fsck` прошёл, SHA-256 записан приватно. Чужие/локальные данные в Git не добавлялись.
- Ветки классифицируются по ancestry, патчам и действующему поведению. Удаление
  выполняется только с проверкой исходного SHA и зависимостей открытых PR.
- Linux release runner проверяет Python/Node/Tk и семь временных SQLite-архивов;
  серверы останавливаются, содержимое архивов сверяется после прогона.
- Hosted CI проверяет Linux/Windows/macOS × Python 3.10/3.12/3.14, Swift SDK,
  native Swift и unsigned Xcode; отдельно собирает wheel/sdist, EXE и DMG.
  Доказательства относятся к точному SHA каждого PR, а не к старым счётчикам тестов.
- Проверки упаковки включают запуск установленного wheel вне checkout,
  сохранность данных Windows install/update/uninstall и embedded core macOS.
- Административный API защиты `main` недоступен GitHub App (HTTP 403).
  Подготовлены [точные настройки и проверка применения](branch-protection.md).

Известная нестабильность: один macOS/Python 3.14 job не завершил дочерний
процесс после успешного набора тестов. Случай и точная приёмка исправления —
P1.1 в ревизии; повторный зелёный запуск не считается устранением причины.
