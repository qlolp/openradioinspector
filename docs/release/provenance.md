# Происхождение и лицензии: реестр незакрытых вопросов

Владелец подтвердил законную лицензию на копию оригинала. Сам договор и разрешение
на распространение/анализ в сессии не предоставлены. Их наличие не подменяется
MIT-лицензией OpenRadioInspector. Правообладатель и условия должны проверяться
по документам, а не по предположениям о типовых лицензиях отрасли.

| Материал | Выполнено | Условие выпуска |
|---|---|---|
| Коммерческий диск: программа, документация, базы, Firebird/Guardant | Удалён из рабочей копии; сохранён закрытый локальный архив; очищена отдельная Git-копия | Перенос архива владельцу, серверная очистка и проверка остаточных refs |
| Полные тексты справки | Удалены из рабочей копии и репетиции истории | Проверить releases, artifacts, LFS, кэши и PR refs |
| Извлечённый индекс справки и подписи UI | Заменены собственными краткими описаниями; старые версии исключены из репетиции истории | Проверить копии материалов под другими путями |
| Аналитические документы, методики и каталог ключевых слов | Сохранены как текущая собственная аналитика; автоматического разрешения публикации нет | Проверить цитаты, заимствования, происхождение таблиц и текста; спорные части исключить |
| Код и вклад разработчиков | Сохранены без изменений при репетиции очистки | Проверить происхождение вклада; закрыть замечания PR |
| NumPy, Python и build tooling | Используются из официальных реестров с проверкой TLS | Сформировать состав каждой поставки, лицензии и уведомления фактически включённых компонентов |
| Опциональные аппаратные и GUI зависимости | Не считаются автоматически включёнными в релиз | Для Windows/macOS/Pi собрать отдельный список библиотек и runtime-компонентов |
| Название, оформление, изображения | Извлечённые UI-подписи убраны | Проверить самостоятельность оформления и отсутствие чужих ресурсов в поставке |

## Ограничения

Проверка по известным Git blob ID обнаруживает известные копии, в том числе
переименованные. Она не обнаруживает все переработанные тексты и не заменяет
проверку происхождения. Пустой Git blob не запрещается: это общие пустые файлы,
включая собственные __init__.py. Запрещённые каталоги проверяются отдельно.

Не публиковать снимки лицензии, серийные номера, закрытые архивы или ключи.
Продолжать исследование оригинала только в пределах проверенных условий.
Юридические вопросы реестра остаются блокером общего выпуска до документированного
решения владельца с привлечением профильного специалиста при необходимости.

## Поставка кандидатов

Сборка включает MIT LICENSE проекта, LICENSE фактического Python, уведомление
pySerial3.5 из официального sdist (источник/хэш в `third_party/README.md`),
собственные NumPy notices. `runtime-notices.json` фиксирует выбранные зависимости
и source SHA; `frozen-files.json` — все фактически упакованные пути, размеры
и SHA-256 без путей сборочной машины. Это не полный лицензионный SBOM:
Tcl/Tk, OpenSSL и прочие native-компоненты требуют отдельной сверки.

В снимке Actions обнаружены только шесть созданных этой подготовкой artifacts
с исходными Python-пакетами и Windows-кандидатами; релизов/вложений релизов нет.
Перед серверной очисткой повторить снимок: текущий набор меняется вместе с CI.
