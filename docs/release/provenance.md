# Происхождение и лицензии: реестр незакрытых вопросов

Ранее владелец сообщил о лицензированной копии оригинала. Договор и условия
распространения и анализа в распоряжении проекта отсутствуют. Владелец
проверяет объём прав по документам для каждой операции и конкретного канала.
MIT-лицензия OpenRadioInspector относится к собственным материалам проекта.

На 23 ноября 2026 года подготовлен проект решения по 160 известным историческим
объектам. Он включает варианты исключения, приватный реестр, проверку реальных
поставок и отдельное поручение на изменение истории. Статус решения — ожидает
подтверждения владельца. [Проект и свежая проверка refs](owner-rights-proposal.md) · [Образец приватной записи](owner-rights-form.md)

## Ограничения

Проверка по известным Git blob ID обнаруживает известные копии, в том числе
переименованные. Она не обнаруживает все переработанные тексты и не заменяет
проверку происхождения. Пустой Git blob не запрещается: это общие пустые файлы,
включая собственные __init__.py. Запрещённые каталоги проверяются отдельно.

Не публиковать снимки лицензии, серийные номера, закрытые архивы или ключи.
Продолжать исследование оригинала только в пределах проверенных условий.
Юридические вопросы реестра остаются блокером общего выпуска до документированного
решения владельца с привлечением профильного специалиста при необходимости.

## Проверка 22 ноября 2026 года

Для защищённого `main` на `deaeeba7` и головы PR #226 на `69cb0795` содержимое дерева прошло `check_public_tree`. В истории каждого из этих коммитов обнаружены 1 022 записи, соответствующие исключённым путям или объектам, в том числе 160 различных ID из списка запрещённых объектов. Архив исходников выбранной ревизии и история полного клона имеют разные результаты. Из этих чисел нельзя установить правовой статус каждого материала.

Повторите две проверки по полному SHA кандидата. Второй запуск возвращает ненулевой код при совпадениях. Общую историю, включая локальные служебные ветки, можно проверить отдельным параметром `--history`.

```sh
python -m tools.release.check_public_tree --revision "$SOURCE_SHA" --summary-only
python -m tools.release.check_public_tree --history-from "$SOURCE_SHA" --summary-only
```

Владелец документирует решение по открытым вопросам происхождения перед публичным выпуском. Переписывание ранее опубликованной истории требует отдельного согласования и проверенной приватной резервной копии. Для каждого установочного пакета и набора изображений дополнительно проверяют фактически включённые файлы, лицензионные уведомления и отсутствие частных данных.

## Поставка кандидатов

Сборка включает MIT LICENSE проекта, LICENSE фактического Python, уведомление
pySerial3.5 из официального sdist (источник/хэш в `third_party/README.md`),
собственные NumPy notices. `runtime-notices.json` фиксирует выбранные зависимости
и source SHA; `frozen-files.json` — все фактически упакованные пути, размеры
и SHA-256 без путей сборочной машины. Это не полный лицензионный SBOM:
Tcl/Tk, OpenSSL и прочие native-компоненты требуют отдельной сверки.

В прежнем снимке подготовки были перечислены шесть CI artifacts с исходными
Python-пакетами и Windows-кандидатами. Для операций с сервером требуется полный
актуальный перечень и проверка содержимого. [Состояние, зафиксированное 23 ноября](owner-rights-proposal.md#что-проверено-23-ноября)
