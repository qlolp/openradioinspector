Порядок объединения #106→#113 сохраняет зависимости. Каждый следующий PR
проверяется с исправлениями предшественников. Старые PR закрываются со ссылкой
на результат; исходные ветки удаляются только после сохранения полезных изменений.

До удалений создан приватный Git bundle, восстановлен отдельный mirror,
выполнен `git fsck`; SHA-256 записан вне репозитория. Для удаления серверных
refs используются точные lease-проверки. Backup и частные журналы не публикуются.
Переписывание истории не выполняется.

Полные решения по исходным веткам: [git-inventory.json](git-inventory.json).
Состояния PR: [pr-decisions.json](pr-decisions.json). `review-disposition.json`
содержит исторический разбор #87; фактическое состояние новых обсуждений
проверяется через GitHub и фиксируется отдельно в решениях текущей уборки.

Результаты ревизии и следующий backlog: [../repository-audit.md](../repository-audit.md).
