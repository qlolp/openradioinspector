# Обязательные проверки main

Workflow проверок и упаковки запускаются для Pull Request, ручного запуска и
push в `main`. Изменения защищённой ветки должны проходить через PR и все
13 контекстов из [main-protection.json](main-protection.json): девять Python/ОС,
wheel/sdist, две desktop-сборки и native-регрессии.

В ходе уборки административный REST API вернул HTTP 403
`Resource not accessible by integration` даже для чтения текущей защиты.
Это ограничение полномочий GitHub App, не результат проверки кода.
Применение защиты не подтверждено.

Администратору: проверить существующие правила и сохранить более строгие
ограничения; затем применить приложенную конфигурацию через Settings → Branches
или REST `PUT /repos/qlolp/openradioinspector/branches/main/protection`.
Для REST нужны права Administration: write. Файл разрешает ноль обязательных
approvals для личного репозитория, но требует PR, актуальную базу, успешные
проверки и закрытые обсуждения; force-push и удаление `main` запрещены.

Проверка результата: прочитать защиту обратно и убедиться, что PR с красным
обязательным контекстом нельзя объединить. Публикация JSON сама по себе
не включает защиту.
