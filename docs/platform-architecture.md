# Архитектура платформы

В инженерных пакетах 0.4.0 служба Rust владеет приборными портами и архивом SQLite. На Raspberry Pi её обслуживает systemd, на Windows и macOS жизненным циклом локального узла управляет комплектный supervisor. Закрытие клиента позволяет продолжить приём. Оператор явно выбирает приборы, запускает сеанс и управляет охраной.

## Измерение, запись и отображение

1. Исполнитель tinySA получает свип для очередного окна плана обзора. У AR-DV1 отдельный исполнитель и очередь настройки. Каждый источник сохраняет свой идентификатор, целочисленные частоты в Гц, интервал UTC и единицы.
2. Ядро фиксирует исходник в транзакции SQLite. Событие опубликованного измерения ссылается на сохранённый источник. Компактный формат v7 хранит ссылку события на исходную панораму. Действующий архив v6 открывается в своём формате. [Хранение и совместимость](compact-panorama-events.md)
3. Клиенты читают состояние и историю через HTTP API. Живые события поступают через SSE или согласованный через capabilities двоичный WebSocket. После разрыва клиент может получить пропущенные измерения из архива. Прореживание спектра применяется при отображении. [Контракты и курсоры](modernization-contracts-and-history.md)
4. Охрана сравнивает совместимые окна с подтверждённым эталоном и учитывает разрешённые сигналы. Исследование связывает событие с исходными панорамами и наблюдениями приёмника. Ручное управление и автоматические задания используют установленную модель владения приборами. [Охрана](rust-guard.md) · [Приборы](rust-instruments.md)

## Клиенты

| Платформа | Состав и подключение |
|---|---|
| Raspberry Pi | ARM64-служба со встроенным React WebUI. Браузер открывает ресурсы установленного узла. [Установка](pi-rc1.md) |
| Windows | Оболочка Tauri с WebView2 использует тот же интерфейс. Можно выбрать локальную службу или сопряжённый удалённый узел. [Устройство локального узла](windows-standalone-rc.md) |
| macOS | Нативный SwiftUI-клиент с Metal-графикой подключается к службе. «Радиомониторинг» и «Исследование» используют общий сеанс. [Пульт](macos-observation-console.md) |

Профиль Mac RC1 поставляется без аудиозахвата и научного worker. Доступность операций определяется составом пакета, профилем прибора и ответом capabilities.

## Разработка и совместимость

Крейты службы находятся в [crates](../crates/), общие контракты и SDK — в [contracts](../contracts/). Код Web и Windows размещён в [clients](../clients/), нативное приложение и Xcode-проект — в [macos](../macos/). Сборщики платформ находятся в [packaging](../packaging/) и [deploy](../deploy/).

Python-библиотека, CLI, исходный HTTP-сервер и Tk-клиент сохраняют собственные точки входа. Исследовательское окружение находится в [research](../research/). Для проверки совместимости используются общие примеры запросов, ответов и измерений. [Python-библиотека](architecture.md) · [API v1](api-v1.md) · [Проверка клиентов](client-core-interop.md)
