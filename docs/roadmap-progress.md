# Продвижение дорожной карты

## 8 ноября 2026: предел архива автономного узла

База этого среза — `feature/macos-request-cancellation`, PR #67, коммит
`1e4afcf0202f026a0977ca9047d2c2adc71fcb50`. Это продолжение открытого стека,
не утверждение о наличии этих возможностей в `main`. Ни одна ветка или PR
этим срезом не объединяется, не закрывается и не удаляется.

Проверены открытые ветки и PR: создание и отмена ControlTask, экспорт NDJSON,
аналитика, независимые политики и отмена HTTP macOS уже реализованы в стеке.
Они не дублируются. Следующий полезный пункт этапа автономного узла — предел
роста архива с предупреждением и без молчаливого удаления измерений.

Реализация: один ограничитель в SQLite-писателе, HTTP 507 при откате пакета,
короткий read-only статус и его отображение в Raspberry Pi WebUI, Windows GUI
и macOS SwiftUI. Контракт и ограничения: [archive-capacity.md](archive-capacity.md).

Это часть критерия ограничения архива, а не полное завершение этапа: физическая
дисковая квота, автозапуск службы, аппаратная USB-восстановляемость, Windows
installer и подтверждённый стенд двух приборов остаются отдельной работой.
Исходный [план проекта](https://github.com/qlolp/openradioinspector/blob/main/docs/roadmap.md)
содержит историческое состояние стека; реальные возможности следует проверять
по конкретной ветке и её API-контракту.
