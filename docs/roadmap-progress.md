## 8 ноября 2026: COM-транспорт общего ядра и явные профили трёх клиентов

[windows-core-serial.md](windows-core-serial.md).

Проверено: 931 Python/Node-сценарий, из них 913 прошли, 18 завершились ошибкой

Windows backend. Семь временных SQLite сохранили полный logical dump, все
собственные серверы остановлены. Compile/syntax/diff checks успешны.

Windows с native COM/USB и реальные приборы не проверены. Прогноз до релиза
и внешние зависимости: [release-readiness.md](release-readiness.md).
