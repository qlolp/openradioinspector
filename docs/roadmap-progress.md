# Продвижение дорожной карты

## 8 ноября 2026: предел архива автономного узла

База этого среза — `feature/macos-request-cancellation`, PR #67, коммит
`1e4afcf0202f026a0977ca9047d2c2adc71fcb50`. Это продолжение открытого стека,
не утверждение о наличии этих возможностей в `main`. Ни одна ветка или PR
этим срезом не объединяется, не закрывается и не удаляется.

Проверены открытые ветки и PR: создание и отмена ControlTask, экспорт NDJSON,
аналитика, независимые политики и отмена HTTP macOS уже реализованы в стеке.
Они не дублируются. Следующий полезный пункт этапа автономного узла — предел
роста архива с предупреждением и без молчаливого удаления измерений.

Реализация: один ограничитель в SQLite-писателе, HTTP 507 при откате пакета,
короткий read-only статус и его отображение в Raspberry Pi WebUI, Windows GUI
и macOS SwiftUI. Контракт и ограничения: [archive-capacity.md](archive-capacity.md).

Это часть критерия ограничения архива, а не полное завершение этапа: физическая
дисковая квота, автозапуск службы, аппаратная USB-восстановляемость, Windows
installer и подтверждённый стенд двух приборов остаются отдельной работой.
Исходный [план проекта](https://github.com/qlolp/openradioinspector/blob/main/docs/roadmap.md)
содержит историческое состояние стека; реальные возможности следует проверять
по конкретной ветке и её API-контракту.

## 8 ноября 2026: сравнение с архивным эталоном

База следующего среза — PR #68 `feature/archive-capacity-guard`, коммит
`8dc88a4d0ca399cd93d76ee26eabdf51a5f06436`. Проверены 67 открытых PR
(#2–#68): отдельного среза сравнения архивных свипов в них нет.

Взят первый приоритет функционального бэклога этапа 5: эталонная панорама
и разность панорам. Реализован ограниченный, законченный сценарий: выбрать
записанный свип как эталон и явно сравнить с другим свипом того же потока.
Ядро выполняет расчёт и проверки совместимости; WebUI, Windows Tk и SwiftUI
показывают разность в dB отдельно от исходных dBm. Документирован контракт
[sweep-comparison.md](sweep-comparison.md).

Сохранённые именованные/усреднённые эталоны, автоматическое обнаружение по
разности и адаптивный порог остаются следующими независимыми срезами. Этап 5
целиком не объявляется завершённым. Открытый стек не объединялся, не закрывался
и не удалялся.

Проверки опубликованного среза: 416 Python/Node, 68 Swift API и 21 native
тест, полная Xcode-сборка без подписи. Реальный локальный API, Swift DTO и
Tk smoke проверены синтетически. Визуальная проверка экрана недоступна из-за
блокировки Mac; Windows OS и приборный стенд не проверялись.

## 8 ноября 2026: именованный каталог эталонов

База — PR #69 `feature/archive-sweep-comparison`, коммит
`8b3108d618b2b90d3aab9072aea954b648608210`. Проверены 68 открытых PR
(#2–#69), дублирующего каталога нет. Продолжен первый приоритет этапа 5:
ссылка на выбранный свип получает имя и сохраняется в общем ядре.

Файловый SQLite schema v3 хранит каталог после перезапуска, три клиента умеют явно
сохранять и повторно использовать запись вне окна последних sweeps.
Идемпотентность предотвращает повторные записи при повторе того же имени и
свипа; неопределённый исход POST предлагается проверить обновлением каталога.
Контракт и миграция: [named-sweep-references.md](named-sweep-references.md).

Усреднение, адаптивный порог, автоматический detector по разности и перенос
каталога между архивами остаются будущими срезами. Удаление/перезапись эталонов
не добавлены; merge/close/delete веток и PR не выполнялись.

Итоговые проверки: 479 Python/Node, 76 Swift API и 28 native тестов прошли;
Xcode собрал приложение без подписи. Реальный синтетический API подтвердил
восстановление каталога и идемпотентное создание. Независимое ревью без
оставшихся замечаний. Визуальная проверка недоступна из-за блокировки Mac;
Windows OS и оборудование не проверялись.

## 8 ноября 2026: адаптивный порог архивного свипа

База — PR #70 `feature/named-sweep-references`, коммит
`1d6046ad8a05e5f959a47fd22762d1f36b903a64`. Проверены 69 открытых PR
(#2–#70): локального адаптивного порога в общем API и трёх клиентах нет.
Выбран следующий приоритет этапа 5, независимо от дальнейшего усреднения
именованных эталонов.

Ядро вычисляет центрированную медиану по точкам и прибавляет заданный запас
в dB; клиенты явно запрашивают анализ одного архивного свипа и показывают
порог в dBm и области строгого превышения. Новые измерения, кандидаты,
команды приборам и миграция не создаются. Реальные архивы не используются.
Контракт: [adaptive-sweep-threshold.md](adaptive-sweep-threshold.md).

CFAR, временное усреднение, автоматическое применение адаптивного порога,
сохранение производных линий и метрологическая проверка остаются отдельными
срезами. Ни один PR или ветка не объединены, не закрыты и не удалены.

Итоговая проверка: 520 Python/Node, 88 Swift API и 39 native-тестов прошли,
сборка Xcode без подписи успешна. Все три клиента проверены на локальном
синтетическом HTTP-сервере; полный логический dump SQLite до/после совпал.
Независимое ревью без оставшихся блокирующих замечаний. Ответ ограничен
2 000 000 байт в клиентах; WebUI и Windows выводят первые 200 областей с
общим счётчиком, график сохраняет все точки принятого ответа. Визуальный
осмотр недоступен из-за блокировки Mac; Windows OS и приборы не проверялись.
