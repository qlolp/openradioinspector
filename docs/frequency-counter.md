# Встроенный частотомер: измерение частоты с погрешностью

Общее ядро измеряет частоту пика архивного dBm свипа в явном окне и
возвращает оценку с честной границей погрешности. Raspberry Pi WebUI,
Windows Tk и macOS SwiftUI позволяют выбрать свип, задать разрешение
частотомера и окно, и получить измерение. Запрос read-only: архивные бины
не изменяются, измерения и события не создаются.

Это седьмой срез функционального бэклога: встроенный частотомер
(«измерение частоты с погрешностью прибора»; в оригинале —
`MEAS_COUNTER_FC_RESULTCODE`, `MEAS_COUNTER_FC_STDOFFSET` и поле
«Разрешение встроенного частотомера, Гц»). Не реализовано: показание
аппаратного счётчика прибора, стандартизованный сдвиг
(`MEAS_COUNTER_FC_STDOFFSET`), серийная калибровка и аттестация.

## Метод

1. Запрос `POST /api/v1/sessions/{id}/frequency-counter` принимает только
   поля `sweep_id`, `resolution_hz`, `start_hz`, `stop_hz`: архивный dBm свип,
   положительное целое разрешение в Гц и окно измерения `start_hz < stop_hz`
   целыми Гц.
2. Внутри окна выбирается бин с максимальным уровнем; при равенстве уровней
   берётся первый (наименьший индекс). Если пик окружён двумя бинами внутри
   окна и локальная сетка равномерна, частота уточняется параболической
   интерполяцией трёх бинов; сдвиг ограничен половиной бина. Во всех остальных
   случаях (пик у края окна, неравномерная или повторяющаяся сетка, нулевой
   знаменатель) измерением считается сам бин пика (`method = "peak_bin"`).
3. Погрешность — граница `max(resolution_hz, raster_hz) / 2`, где
   `raster_hz` — шаг локальной сетки (0 без равномерного соседства). Это
   честная оценка: интерполяция уточняет точку, но измерение не обещает
   лучше разрешения прибора и записанного растра одновременно.

## Результат и связь с каталогом методик

Ответ содержит `measured_frequency_hz`, `uncertainty_hz`, `method`,
`peak_*`, `raster_hz`, `resolution_hz` и `values` — готовый объект для записи
через `POST /api/v1/sessions/{id}/measurement-results` с методикой
`frequency_counter` (каталог методик, см.
[measurement-results.md](measurement-results.md)). Запись выполняется
отдельным явным действием: частотомер сам по себе ничего не сохраняет.

## Совместимость и ограничения

Измерение — производная оценка по записанным данным, а не показание
аппаратного счётчика и не аттестованное средство измерений. Погрешность
не включает дрейф опорного генератора прибора, погрешность тракта и
антенны — это зона ответственности оператора. Окно обязано содержать хотя
бы одну точку свипа; иначе — 409 `counter_incompatible`. Старый сервер без
маршрута отвечает 404; невалидная форма запроса — 400 `invalid_request`.
