# Справочник ключевых слов протоколов измерений

Документ воспроизводит словарь подстановок, применённый в исходном комплексе
для автоматического формирования протоколов измерений. Словарь извлечён из
раздела «Ключевые слова при формировании протокола…» руководства по
формированию отчётов.

## 1. Синтаксис

Значение подставляется в шаблон отчёта по ключевому слову в форме

```
#ИмяКлючевогоСлова#
```

* Регистр **значим**: `#MOFBN_Res#` и `#MOFBB2_Res#` — разные ключевые слова.
* Допустимы латинские буквы, цифры и подчёркивание.
* Если значение ключевого слова отсутствует, оно заменяется пустой строкой —
  соответствующий фрагмент шаблона исчезает.
* В OpenRadioInspector дополнительно поддерживается синтаксис `{{ключ}}` с
  подстановкой значения «н/д» при отсутствии данных; он не совпадает с
  синтаксисом оригинала и предназначен для собственных шаблонов проекта.

## 2. Табличные блоки

Таблица в шаблоне обрамляется маркерами: начало — `#D1#`, `#D2#` или `#D3#`,
окончание — соответственно `#1D#`, `#2D#` или `#3D#`. Текст между маркерами
является шаблоном строки и повторяется по числу записей. Если записей нет,
блок удаляется из отчёта целиком.

| Таблица | Маркер начала | Маркер окончания | Тип содержимого |
|---|---|---|---|
| 1 | `#D1#` | `#1D#` | Результаты измерений контрольной полосы и внеполосовых излучений |
| 2 | `#D2#` | `#2D#` | Протокол множественных измерений напряжённости поля |
| 3 | `#D3#` | `#3D#` | Результаты измерений по детекторам измерительного приёмника |

## 4. Программный доступ

```python
from radioinspector.keywords import CATALOG, keyword_group, known_keywords

len(CATALOG)                      # 317
keyword_group("MOFBB2_Res")       # группа по виду измерений
known_keywords()                  # перечень ключевых слов в алфавитном порядке
```

Полный перечень доступен из командной строки:

```bash
python3 -m radioinspector keywords
python3 -m radioinspector keywords --json
```

## 5. Ограничения

* Словарь описывает **названия и назначение** полей, но не их форматы и
  единицы измерения: единицы указаны в тексте описаний и частично в
  самих шаблонах оригинала.
* Разбор конкретных шаблонов отчётов оригинала (файлы `.doc`) не
  воспроизводится: движок работает с текстовыми шаблонами Markdown/HTML.
* Ключевые слова, добавленные оригиналом после выпуска руководства, в
  словарь не входят.
