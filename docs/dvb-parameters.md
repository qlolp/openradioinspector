# Параметры DVB-T: сверка с пороговыми значениями

Общее ядро сравнивает введённые параметры DVB-T — MER, BER после Витерби
и после Рида — Соломона — с явными пороговыми значениями и возвращает
код результата и вердикт по каждому параметру. Защитный интервал и
скорость кодирования задаются из стандартных наборов. Raspberry Pi WebUI,
Windows Tk и macOS SwiftUI показывают форму ввода и вердикты. Запрос
read-only: архив не изменяется.

Это восьмой срез функционального бэклога: измерение параметров DVB-T.
Реализована та часть, что опирается на «Пороговые значения параметров
DVB-T» и таблицу кодов результата (`MEAS_DVB_RESULTCODE`) оригинала:
сверка чисел с порогами и раздельное хранение вердикта. Не реализовано:
демодуляция IQ-данных, измерение MER/BER прибором, time-слоты и полный
приёмный тракт DVB-T.

## Параметры и пороги

1. Параметры: `mer_db` (дБ), `ber_after_viterbi` и `ber_after_rs`
   (от 0 до 1). Пороги: `min_mer_db`, `max_ber_after_viterbi`,
   `max_ber_after_rs` (от 0 до 1). Все значения — конечные числа.
2. `guard_interval` — один из `1/32`, `1/16`, `1/8`, `1/4`;
   `code_rate` — один из `1/2`, `2/3`, `3/4`, `5/6`, `7/8`.
3. Вердикт: MER ≥ `min_mer_db`, BER ≤ своего максимума. Равенство
   порогу считается нормой. Код результата `norm` — все параметры в
   норме, `not_norm` — хотя бы один вне.

## Результат и связь с каталогом методик

Ответ содержит параметры, пороги, вердикты (`verdicts`) и `values` —
готовый объект для записи через `POST /api/v1/sessions/{id}/measurement-results`
с методикой `dvb_t_parameters` (каталог методик, см.
[measurement-results.md](measurement-results.md)). Код результата хранится
отдельно от значений, как `*_RESULTCODE` оригинала.

## Совместимость и ограничения

Код результата — признак по введённым числам и порогам, а не измерение,
не нормативное заключение и не аттестация. Сами MER и BER поступают из
прибора или оператора: демодуляция сигнала и измерение параметров
аппаратурой не выполняются и не заявляются. Старый сервер без маршрута
отвечает 404; невалидная форма запроса — 400 `invalid_request`;
значения вне диапазонов — 409 `dvb_evaluation_error`.
