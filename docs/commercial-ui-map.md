# Карта интерфейса RadioInspector по ресурсам форм

Документ перечисляет подписи элементов интерфейса, извлечённые из ресурсов
форм `InspectorRT.exe` — то есть то, что видно на экране программы, без её
запуска. Источник: 135 ресурсов RCDATA, из них 133 формы Delphi; подписи
прочитаны напрямую из ресурсов, а не разбором дерева компонентов, поэтому
охват выше, чем при структурном разборе.

Воспроизведение — программами из [`tools/analysis/`](../tools/analysis/README.md):
подписи извлекаются из блоков форм и фильтруются по признакам «похоже на
текст интерфейса». Список машинно-собран, поэтому в нём встречаются обрывки
фраз и дубли в разном регистре.

Документ отвечает на вопрос «что есть на экране», но не на вопрос «что
происходит при нажатии»: поведение восстанавливается по руководствам комплекта
и по наблюдению работающей программы.

## 1. Как программа сообщает об отсутствующих опциях

Отдельная находка: сама программа содержит сообщения о неустановленных
опциях. По ним виден точный набор имён, который использует лицензионная
проверка.

| Опция в бинарнике | Сообщение программы |
|---|---|
| `AdvancedDB` | Не установлена опция 'AdvancedDB' |
| `DTest` | Не установлена опция  'DTest' |
| `Meas` | Не установлена опция 'Meas' |
| `MeasDB` | Не установлена опция 'MeasDB' |
| `RC-Meas` | Нет опции 'RC-Meas'. |
| `RC-MeasDB` | Не установлена опция 'RC-MeasDB' |
| `RC-RemoteMD` | Отсутствует опция 'RC-RemoteMD' |
| `RC-SA` | Нет опции 'RC-SA'. |
| `RC-Sound` | Отсутствует опция 'RC-Sound' |
| `RF Spectrum DIGI-Scan` | В приборе отсутствует опция 'RF Spectrum DIGI-Scan' |
| `RemoteMD` | Отсутствует опция 'RemoteMD' |
| `rcSound` | Отсутствует опция 'rcSound' |

Сообщения вида «Light version (only scanning receivers)» и «"RemoteMD" option is
not installed» подтверждают: вариант Light — это та же программа InspectorRT с
неполным набором лицензионных возможностей, а не отдельная реализация.

## 2. Форматы файлов из фильтров диалогов открытия

Подписи диалогов открытия файлов раскрывают рабочие форматы оригинала, часть
которых не встречается в руководствах.

| Формат | Назначение по подписи |
|---|---|
| `*.pan` | база данных панорам диапазонов |
| `*.pan` (спектрограмма) | спектрограмма |
| `*.tsks` | пакет заданий (`RInspectorRC - пакет заданий`) |
| `*.rimp` | точки измерений (`RadioInspector - точки измерений`) |

Пакет заданий `*.tsks` и файл точек измерений `*.rimp` — два формата, которых
нет ни в перечне рабочих папок, ни в таблице базы планирования: первый
описывает набор заданий, второй — выгрузку результатов измерений в виде
точек. Это кандидаты в раздел «бэклог возможностей оригинала».

## 3. Что эта карта не заменяет

Карта даёт состав экранов и надписей, но не поведение. Чтобы закрыть
поведение, нужно наблюдение работающей программы: снимки экрана или запись
экрана с проходом по вкладкам. По ним определяются последовательность
действий, значения по умолчанию, реакции на ошибки и то, какие элементы
доступны при включённых опциях.

Минимальный набор снимков для закрытия темы: главное окно, вкладка контроля
диапазона, диалог задания на сканирование, диалог действий при обнаружении
сигнала, форма измерения параметров сигнала, настройки порога и общие
установки, диалог авторизации, окно сохранения списка сигналов и просмотр
спектрограммы.
