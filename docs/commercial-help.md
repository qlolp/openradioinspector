## 3. Ключевые находки

Справка оказалась не пересказом руководств, а вторым, независимым источником:
она описывает работу экранов и содержит алгоритмы измерений, реализованные в самой
программе. Ниже — то, чего в прилагаемых руководствах нет.

### 3.1. Алгоритмы измерений в редакции самой программы

Файл `MeasHelp.hlp` содержит четыре методики с формулировкой «Алгоритм выполнения
измерений, реализованный в ПО Inspector»:

* ширина полосы методом β/2 (со ссылкой на п. 3.4.1 Справочника МСЭ и
  ITU-R SM.328-10), с кусочно-линейной интерполяцией границ по мощности;
* ширина полосы по уровню −N дБ: порог `Uпорог = Umax − N`, перебор элементов
  массива влево от `Umax` до элемента `n` с условием `U(n) < Uпорог` **и**
  `U(n−1) > Uпорог`, затем интерполяция между `n−1` и `n`;
* напряжённость поля: поиск максимума в исходном массиве, отсечение сигнала от
  шумовой дорожки, усреднение выборки двумя способами — по медиане и по среднему;
* центральная частота методом центра тяжести: выделение сигнала над уровнем
  шумовой дорожки с поиском границ от центра массива наружу.

Погрешность результата по частоте в справке определена как погрешность
измерений частоты средства измерений.

### 3.2. Сверка методики −N дБ с нашей реализацией

Расхождений нет, и справка их исключает. Условие `U(n) < Uпорог` в справке
дополнено `U(n−1) > Uпорог`, где `n−1` — предыдущий элемент по направлению
обхода; при переборе влево от `Umax` это условие выполняется автоматически, и
наша реализация (ближайшая точка вне полосы с интерполяцией между границами)
совпадает с ним.

Сверка выполнена на 300 случайных трассах с провалами внутри сигнала: ни по
левой, ни по правой границе различий нет. Тем самым справка подтверждает
исправление, сделанное в релизе 0.2.0: формулировка §11.2 руководства была
неоднозначна по индексации, формулировка справки («перебор всех элементов
массива влево от элемента Umax») однозначна.

### 3.3. Редактирование линии порога мышью

Файл `ThresholdControl.hlp` описывает работу с линией порога подробнее, чем
руководство: при захвате линия отображается втрое толще, над полем графиков
появляется вспомогательное окно, точки перелома создаются и удаляются щелчком
по красной окружности, отдельный участок линии перемещается между маркерами,
а произвольные прямые и кривые проводятся протяжкой мыши. Линия порога может
загружаться из сохранённой трассы при совпадении параметров сканирования, а при
продолжении записи в существующий файл базы панорам используется ранее
отредактированная линия. В справке приведён пример формирования порога «шум
плюс 4 дБ» для регистрации слабых шумоподобных сигналов.

### 3.4. Эталонная панорама и разность панорам

Файл `InspectorHelpGraph.hlp` описывает подпункт меню «Эталонная панорама» для
визуального сравнения текущих измерений с ранее сохранённой панорамой и окно
выбора условия разности: вариант «Отображать 2D график разности панорам»
показывает разность в объёмном виде, вариант с положительной частью — только
выше нуля. Там же описано подчёркивание сигналов из базы данных частотных
присвоений: длина полоски подчёркивания соответствует числу территориально
разнесённых передатчиков на одной частоте, а при нескольких записях передатчик
выбирается из выпадающего списка.

### 3.5. Справка шире, чем поставленная программа

Три файла справки — `ControlPoints.hlp` (10 тем), `Phonogramm.hlp` (11 тем) и
`NewSignalsSearch.hlp` (10 тем) — описывают экраны, которых в модуле нет:
соответствующих форм `TFRCONTROLPOINTS`, `TFPHONOGRAM` и
`TFRNEWSIGNALSSEARCH` в ресурсах `InspectorRT.exe` не обнаружено. Значит,
справка писалась для более широкого комплекса, чем поставленный пакет, и
часть описанных возможностей в дистрибутив Light не дошла.

Обратная история — с `SignalsList.hlp`: все три его темы помечены автором
как «Извините, данный раздел находится в стадии оформления». Это единственный
файл справки с незавершёнными разделами; остальные 23 файла содержат готовый
текст.

### 3.6. Что подтвердилось

Разделы справки независимо подтверждают выводы предыдущих разборов: работа
InspectorRT локально без I_MasterDevice, встроенная опция записи и анализа
фонограмм, три метода поиска опасных сигналов (разность панорам, сравнение с
порогом, сравнение с эталонной панорамой), загрузка эталонной панорамы и
разности панорам в поле графиков, а также независимость масштаба отображения
графиков от масштаба анализатора спектра.
