# Экспорт усреднённого анализа

WebUI, Windows и macOS могут сохранить текущий проверенный результат
сравнения/обнаружения в локальный JSON-файл. Экспорт доступен только после
успешного ответа ядра и относится к конкретному результату: изменение
параметров, очистка или новый запрос не позволяют экспортировать старый
снимок. В файл входят исходные уровни target, производные уровни сравнения,
параметры и области обнаружения, единицы и происхождение источников.

Формат файла:

```json
{
  "format": "openradioinspector-sweep-average-change-detection",
  "format_version": 1,
  "data": {
    "comparison": {},
    "detection": {}
  }
}
```

`data` сохраняет результат API без преобразования единиц. В `comparison`
частоты остаются целыми Hz; исходные уровни и средняя линейная мощность
представлены в dBm, их знаковая разность — в dB. Поля `reference.source_ids`
и `reference.sources` сохраняют порядок, интервалы UTC и записанные настройки
всех источников. В `detection` остаются порог, минимальная ширина и точные
границы областей. Объект не содержит нового ID измерения или опорного и не
является импортируемым архивным форматом.

Файлы создаются только по действию оператора. WebUI передаёт файл браузеру;
завершение загрузки определяет браузер. Windows и macOS записывают выбранный
путь атомарной заменой; отмена диалога не меняет результат и файловую систему.
Экспорт не передаёт данные серверу, не изменяет SQLite и не создаёт
кандидатов, событий, задач или команд прибору. Включённый формат версии 1
документирован, но отдельные импорт/повторное воспроизведение пока не
реализованы.
