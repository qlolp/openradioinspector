# Приёмка OpenRadioInspector Field

Целевой телефон — Galaxy S22 Ultra, Android 12 или новее, ARM64. Укажите модель SM-S908…, версию Android и One UI, версию приложения и SHA сборки. Публичный статус совместимости присваивается конкретному сочетанию прибора и прошивки по результатам испытаний.

## Перед выездом

Подготовьте USB OTG-переходник с передачей данных, подходящий кабель, приёмную антенну и штатное питание AR-DV1. Для каждого прибора создайте отдельный выезд. Проверьте фактически активный вход, свободное место, заряд и ожидаемую длительность записи. Включите GPS при старте нужного выезда. Системный запрос USB относится к выбранному устройству. Для повторного подключения разрешение может потребоваться снова.

## Первый выезд

1. На время установки соедините телефон с Mac кабелем для передачи данных. Для установки через ADB включите отладку по USB в параметрах разработчика и подтвердите на телефоне ключ этого Mac. В выводе `adb devices -l` у телефона должен появиться статус `device`. [Установка тестового APK](../../clients/android/README.md)
2. Отсоедините телефон от Mac, подключите один прибор через USB OTG и откройте **OpenRadioInspector Field**. На вкладке **«Прибор»** выберите USB-устройство, профиль и задание. По необходимости включите GPS. Нажмите **«Начать приём»** и разрешите доступ к прибору.
3. Откройте **«Сигнал»**. Для анализатора здесь видны панорама и водопад, для AR-DV1 — последовательность исходных отсчётов S-метра. Заметка сохраняет ссылку на показанное измерение. До первого измерения заметка относится к выезду.
4. Нажмите **«Стоп»**, откройте завершённый выезд в **«Архиве»** и выберите **«Экспортировать .orifield…»**. Перенесите файл на Mac и откройте его из Finder в сборке с поддержкой полевых архивов. Сверьте ссылку в заметке с исходным измерением.

Если GPS дольше 15 секунд не присылает свежих координат, приложение фиксирует разрыв, а со следующей пригодной координаты начинает новый участок трека. Перед пределом ZIP V1 (4 ГиБ) запись текущего выезда завершается с запасом для экспорта. Для продолжения начните новый выезд.

## Три аппаратных прогона

Каждый прогон длится минимум два часа. Запишите UTC начала и конца, время погашения и включения экрана, заряд и температуру батареи в начале и конце, изменения питания, свободное место, объём архива, количество полных измерений и разрывов. Основную часть времени экран погашен. Устройство работает в обычном режиме энергосбережения владельца. В ходе каждого выезда поставьте отметку до погашения экрана и после разблокировки.

| Прибор | Задание | Что проверить в архиве |
|---|---|---|
| RF Explorer 3G Combo Standard 1.34 | Правый вход, 100–400 МГц, затем весь вход 15–2700 МГц, шаг 10 кГц | На завершённый проход соответственно 30 001 частота в 268 окнах и 268 501 частота в 2398 окнах. Сверить сетку и перекрытия, RBW, идентификаторы окон, измеренное время возврата. |
| tinySA Ultra | Поддерживаемый RX-профиль, например 88–108 МГц | Подтверждение режима input, исходные свипы в дБм, шаг фактической сетки, оба края диапазона и время каждого обзора. |
| AOR AR-DV1 | Частота, список, FM-диапазон минимум на 1001 допустимую частоту | Подтверждённая настройка, исходный S-метр, контроль точки 1000 и 1001. Сверить число наблюдений, пропуски и порядок при переходе между участками. |

Отдельно воспроизведите отказ в USB-разрешении, извлечение кабеля в процессе чтения, повторное подключение, потерю GPS и отказ записи при исчерпании места во временном тестовом хранилище. Проверьте сохранность ранее записанного и явное состояние остановки. Завершив выезд, перенесите файл на Mac. Откройте его из Finder, сверьте число строк, ID и значения крайних измерений, UTC, единицы, трек и переходы из заметок. Повреждённая копия должна дать ошибку. Приложите к приватному протоколу результат каждого пункта и версию macOS. Для публичной документации используйте учебный маршрут без личных координат.

Для независимой проверки сетки откройте файл в просмотрщике и возьмите значения stream_id и pass_id одного завершённого прохода. Из корня репозитория выполните:

```sh
python tools/field/verify_rf_pass.py session.orifield STREAM_ID PASS_ID 100000000 400000000
```

Команда сверяет каждую частоту, значения и единицы, номера и количество окон, включая перекрытие в конце. Она проверяет сетку одного прохода. Длительность работы телефона, состояние экрана и происхождение сигнала фиксируются отдельно в протоколе стенда.

## Google Play

1. Владелец регистрирует и верифицирует личный аккаунт Play Console и устройство. Название приложения — OpenRadioInspector Field. Поставка бесплатная, без рекламы. Контакт поддержки и конфиденциальности издателя — 9218907903@mail.ru.
2. Проверьте AAB релизной сборки, целевой API 36 или действующее более высокое требование, совместимость всех нативных библиотек со страницами 16 КиБ и обновление с предыдущей сборки. Загрузочный ключ хранится у издателя. Подпись распространения — Play App Signing.
3. После проверки фактического поведения пакета заполните Data safety, укажите обработку местоположения, приложите публичную страницу политики и демонстрацию запуска и остановки USB/GPS foreground service. Скриншоты карточки снимите с принятой версии на S22, на учебных данных. Укажите отдельно доступные аппаратные профили.
4. Через внутренний трек проверьте установку из Play. В закрытом тесте нового личного аккаунта минимум 12 участников остаются подключёнными непрерывно не менее 14 дней. Соберите отзывы и историю исправлений. После получения доступа к production опубликуйте принятую сборку и проверьте установку из публичной карточки. Сохраните ссылку и versionCode в статусе выпуска.

Порядок сборки и выдачи подписанного пакета, безопасный переход с debug APK, проверка данных при смене канала и условия публикации в GitHub приведены в [инструкции по распространению Field](distribution.md).
