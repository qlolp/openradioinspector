# Карточка для закрытого теста Google Play

**Название** — OpenRadioInspector Field

**Краткое описание** — Полевой спектроанализ по USB с GPS-отметками и переносом измерений на Mac.

**Описание** — Подключите к Android-телефону один прибор и начните выезд. С RF Explorer или tinySA смотрите панораму и водопад. С приёмником AR-DV1 наблюдайте уровень на частоте, проходите список или диапазон. Отмечайте интересующие измерения. По вашему выбору приложение запишет трек GPS. Готовый выезд открывается в совместимой версии OpenRadioInspector на Mac. Для работы нужен кабель с передачей данных, поддержка USB Host и питание прибора. Приложение бесплатное и работает офлайн.

**Поддержка и конфиденциальность** — 9218907903@mail.ru.

После включения политики в `main` откройте страницу без входа, сверьте контакт и укажите её публичный адрес в Play Console. [Публичная политика конфиденциальности](https://github.com/qlolp/openradioinspector/blob/main/docs/field/privacy.md)

Перед production дополните карточку точными моделями и прошивками по физическим протоколам, ссылкой на [политику конфиденциальности](privacy.md) и снимками этого Android-приложения. Для проверки длительной записи приложите видео с началом выезда, запросом геолокации, уведомлением активной службы и действием остановки. Протоколы с настоящими маршрутами остаются у оператора.
