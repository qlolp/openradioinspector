# OpenRadioInspector Field — конфиденциальность

Редакция от 22 ноября 2026 года. Издатель приложения предоставляет контакт для обращений в карточке Google Play. С разработчиками OpenRadioInspector также можно связаться через [страницу проекта](https://github.com/qlolp/openradioinspector). Для публичных сообщений используйте описание проблемы без личных координат и маршрутов.

### Данные полевого выезда

Приложение сохраняет на телефоне время и параметры приёма, частоты и уровни сигнала, сведения о подключённом приборе и добавленные оператором заметки. Если оператор включил GPS и разрешил доступ к местоположению, приложение также сохраняет координаты, время определения и доступную точность во время записи выезда. При погашенном экране сбор продолжается службой с системным уведомлением. Действие остановки завершает приём и сбор координат.

### Хранение и передача

Рабочая база хранится в закрытом каталоге приложения. Приложение работает без регистрации, рекламы и сервера сбора данных. Оператор может сохранить файл выезда в выбранное через системный диалог место. Файл содержит измерения, заметки и записанный маршрут. Если выбрать облачное хранилище, дальнейшую обработку файла выполняет его провайдер.

Для удаления всей локальной истории откройте сведения о приложении в настройках Android и очистите его данные. Сохранённые вручную копии удаляются отдельно из места экспорта. Доступ к местоположению можно отозвать в разрешениях приложения.
