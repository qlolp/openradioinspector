# Возможности RadioInspector Light 32314

Документ содержит проверяемый инвентарь возможностей дистрибутива
**RadioInspector Light 32314** — пакета измерительных программ, поставляемого
на компакт-диске. Источники — файлы самого дистрибутива (описание пакета
`ReadMe.txt`, техническое описание `RadioInspector datasheet rus rev. draft1.pdf`,
комплект руководств оператора в каталоге `InspectorDoc/`, изменение
программного обеспечения, базы данных FireBird и состав рабочих папок) плюс
публичные сведения производителя.

Инвентарь описывает **фактический периметр конкретного пакета**, а не всего
программного обеспечения линейки. Различие существенно: линейка включает
девять программ, а пакет 32314 содержит одну.

## 1. Что такое RadioInspector Light 32314

| Характеристика | Значение | Источник |
|---|---|---|
| Продукт | RadioInspector Light — вариант программы InspectorRT | `ReadMe.txt`, datasheet |
| Номер пакета (номер ключа) | 32314 | `ReadMe.txt` |
| Состав СПО пакета | `RInspectorRT` | `ReadMe.txt` |
| Версия сборки | 7.6.0.1 | `InspectorRT.exe` (ресурсы) |
| Заголовок окна | `RInspectorRT - "Light" version` | `InspectorRT.exe` (ресурсы) |
| Поддерживаемые средства измерений | только сканирующие приёмники | `ReadMe.txt` |
| Тип лицензии | электронный ключ (драйверы Guardant на диске) | `ReadMe.txt`, каталог `Драйверы ключей защиты/` |
| Тип носителя | компакт-диск с установщиком `SetupRadioInspectorLight` | каталог `Program Files/32314/` |

**Light — не урезанный InspectorRC.** Это вариант InspectorRT: та же
программа, тот же интерфейс, те же девять задач, но без управления
анализаторами спектра. Формулировка datasheet: «Программа аналогичная
RInspectorRT, но без возможности управления анализаторами спектра (только
управление сканирующими приемниками)».

Отличия от полного InspectorRT, зафиксированные в руководстве «Состав и
назначение комплекса программ»:

* работа с приборами локально, без программы I_MasterDevice;
* не поддерживается геоинформационная система;
* нельзя управлять средствами измерений по сети;
* одновременно может быть запущена только одна программа InspectorRT;
* запись и анализ фонограмм и управление сканирующим приёмником-аудиоконтролем
  встроены в программу.

### 1.1. Включённые опции

Состав опций взят из `ReadMe.txt` пакета; сопоставление дано с datasheet и
номенклатурой 2017 года.

| Опция (новая номенклатура) | Состояние в пакете 32314 | Что даёт |
|---|---|---|
| Light-SList | есть | База данных частотных присвоений, линия порога, список сигналов, превысивших порог |
| Light-Sound | есть | Запись и анализ демодулированного аудиосигнала, задание на запись при превышении порога |
| SimpleDB | есть | Простая база данных известных сигналов: одна строка — одно РЭС, одна частота, один владелец; бесплатный конвертер из CSV |
| Light-RemoteMD | нет | Управление сканирующим приёмником по сети, передача демодулированного аудиосигнала в реальном времени |
| Light-SoundScaner | нет | Управление вторым сканирующим приёмником как средством аудиоконтроля без остановки сканирования |
| SA | спорно | В `ReadMe.txt` опция указана дважды — «RC-SA — есть» и «RC-SA — нет»; фактический состав не определяется |

Две особенности опций, важные для понимания пакета:

* **Опции не равны функциям.** `MeasDB` (база результатов измерений) требует
  `AdvancedDB` + `SA` + `Meas`; в пакете 32314 используется `SimpleDB`, а
  `MeasDB` недоступна. Поэтому программа **не пишет результаты измерений
  параметров сигнала в базу** — это следствие конфигурации опций, а не
  ограничения программы.
* **Программа поставляется только с опциями.** В datasheet программы без
  опций помечены знаком «*» и не поставляются отдельно.

## 3. Задачи программы

Девять задач InspectorRT (Книга 7, §1.1) — ядро Light:

1. Оперативный и долговременный радиомониторинг: достоверная информация о состоянии радиочастотного спектра за всё время наблюдения.
2. Сбор всех данных наблюдений для хранения, обработки, воспроизведения и детального анализа.
3. Поиск незаконно действующих передатчиков (НДП) тремя методами: разнесённые антенны, сравнение с эталонной панорамой, сравнение с электромагнитной обстановкой предыдущего сеанса.
4. Детальное исследование излучений отдельных передатчиков в пространстве «амплитуда — частота — время».
5. Тестирование обнаруженных излучений на принадлежность к классу аналоговых телевизионных сигналов, в том числе с использованием методов кодирования сигнала.
6. Демодуляция и аудиоконтроль радиосигналов с использованием дополнительного сканирующего приёмника.
7. Запись демодулированного аудиосигнала с последующим анализом и воспроизведением, в том числе в автоматическом режиме при превышении линии порога или обнаружении нового сигнала.
8. Предварительный анализ спектра по частотной и временной оси для поиска передатчиков со сложными алгоритмами скрытия работы: накопление информации, перестройка по частоте, широкополосные и шумоподобные излучения.
9. Выдача сигналов тревоги на удалённый компьютер при обнаружении опасных сигналов.

### 3.1. Средства и методы

Из Книги 7, §1.1 (сокращённо):

* панорамы текущих, максимальных, минимальных и усреднённых значений;
* спектрограмма («водопад») в 2D и 3D без ограничений по времени записи;
* эталонная панорама и разность панорам, в том числе с антенным коммутатором и разнесёнными антеннами;
* управляемая линия порога и список сигналов, превысивших порог;
* адаптивное значение линии порога — огибающая по минимуму превышения графика максимумов;
* минимальная мощность регистрируемого излучения при формировании списка сигналов;
* база данных частотных присвоений для идентификации легальных сигналов;
* анализ демодулированных аудиосигналов в режиме осциллографа и низкочастотного анализатора спектра;
* запись фонограмм с 5-секундным отрезком, предшествующим началу записи, анализ и редактирование;
* автоматическая запись демодулированного аудиосигнала при превышении линии порога, в том числе при удалённом управлении;
* сигнал тревоги при обнаружении нового мощного излучения или телевизионного сигнала;
* маркерные и курсорные измерения, масштабирование по частотной и временной оси;
* формирование заданий на сканирование, продолжение записи в ранее сохранённую базу панорам;
* отчёты об исследованных диапазонах и найденных сигналах.

### 3.2. Три уровня выполнения измерений

Книга 10 «Измерения в ручном, автоматизированном и автоматическом режимах»
описывает трёхуровневую модель:

| Уровень | Кто исполняет | Содержание |
|---|---|---|
| 1. Ручной (экспертный) | Инспектор DC | Разовое исследование параметров сигнала оператором |
| 2. Автоматизированный | Инспектор RC | Список фиксированных частот; при обнаружении сигнала вызывается DC и результат пишется в базу результатов измерений |
| 3. Автоматический | Планировщик | Задание по расписанию, ночные и длительные сеансы |

Для пакета 32314 уровень 2 ограничен: запись в базу результатов требует опции
`MeasDB`, которая недоступна при `SimpleDB`.

### 5.1. Измерение параметров DVB-T(H)

Отдельное руководство (Книга 9) описывает измерение параметров цифрового
телевидения анализатором Rohde&Schwarz ETL:

* тип модуляции (16QAM, 64QAM, QPSK и другие);
* режим модуляции (F2K…F8K);
* защитный интервал (например, 1/32);
* напряжённость поля по интегральной мощности сигнала;
* MER (rms), дБ;
* BER до декодера Витерби, после декодера Витерби, после кода Рида — Соломона;
* смещение центральной частоты, Гц;
* скорость кодирования для высоко- и низкоприоритетного потоков (H/L);
* для каждого измерения сохраняются геодезические координаты, время и график
  спектра сигнала (±6 МГц от центра).

Результаты сохраняются в файлы `*.i_dvb`; InspectorRP строит по ним зоны
покрытия.

### 5.2. Требования к IQ для цифровых стандартов

Документ «Требования к IQ» задаёт алгоритм работы при анализе нескольких
цифровых стандартов одновременно:

* `Fd` — максимальная требуемая частота дискретизации (для DECT — 2000 кГц);
* `L` — максимальная требуемая длительность записи (TETRA — 1,076 с,
  GSM — 0,98 с, APCO25 и DMR — 0,8 с, DECT — 0,2 с, AnalogTV — 0,1 с);
* `M = Fd · L` — необходимый объём памяти;
* при недостатке памяти `L1 = M_доступное / Fd`, и стандарты с требованием
  больше `L1` не анализируются;
* при недостаточной частоте дискретизации анализ невозможен.

Пример документации: Rohde&Schwarz FSU (523 776 слов IQ) при наборе
{TETRA, APCO25, DMR, GSM, Bluetooth, DECT} получает `L1 = 0,26 с` — анализ
проходят только DECT и AnalogTV.

*Замечание по исходному тексту:* в примере величина `L` указана как «1 с
(определяется стандартом GSM)», тогда как таблица длительностей того же
документа даёт для GSM 0,98 с, а для TETRA — 1,076 с. Алгоритм с табличными
значениями даёт `L = 1,076 с`; расхождение сохранено как расхождение
источников.

## 8. Выводы для проекта

1. **Цель копирования — не весь функционал линейки, а пересечение трёх
   множеств:** документированные возможности RT-Light ∩ включённые опции
   ∩ класс приборов «только сканирующие приёмники». Для пакета 32314 это
   примерно треть возможностей InspectorRT.
2. **Три уровня выполнения измерений — каркас, а не деталь.** Уровни 1 и 3
   покрыты, уровень 2 (список фиксированных частот с условием действия) до
   этой работы не был представлен.
3. **База планирования богаче модели задания аналога.** Запись `TASKPLAN`
   содержит справочники, служебные даты, состав оборудования и исполнителей,
   результат, мобильность и вложения — всё это перенесено.
4. **Диагностика изрезанности спектра — рабочая методика, а не
   косметика.** Правило «число обнаружений больше числа циклов сканирования»
   позволяет отличить узкополосный сигнал от широкого сигнала с
   изрезанным спектром; в аналоге оно реализовано как свойство записи.
5. **Расчёт требований к IQ переносим, декодеры — нет.** Алгоритм расчёта
   `Fd`, `L`, `M`, `L1` реализован; цифровые демодуляторы оригинала закрыты
   и не воспроизводимы.
6. **Не переносимы:** электронный ключ Guardant, сервер FireBird, ГИС
   MapInfo/OpenStreetMap, проприетарные драйверы приборов, сетевой протокол
   MasterDevice и I_RemoteCheck.
7. **Приоритет следующих работ:** эталонная панорама и разность панорам;
   адаптивная линия порога; измерение параметров DVB-T(H); задание на
   контроль фиксированных частот с автозапуском из планировщика.
