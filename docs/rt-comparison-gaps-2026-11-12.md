# Реальные разрывы с RadioInspectorRT: сводка по внешнему анализу (сверено с кодом) — 12 ноября 2026

Дополнение к [`rt-comparison.md`](rt-comparison.md). Основано на внешнем
сравнительном анализе RadioInspectorRT (сторонний документ), но сверено с
кодом текущего `main` (`80c549c`). Важная оговорка: исходный внешний документ
сравнивал RT с *типовыми* открытыми SDR-инструментами (QSpectrumAnalyzer,
Specmon2, SDR++, SDR-Shark) и **не имел доступа к репозиторию**, поэтому часть
его «отставаний» к OpenRadioInspector неприменима. Здесь оставлена только
валидная часть.

## 1. Что из внешнего анализа уже реализовано (не является разрывом)

| Внешний тезис | Факт в OpenRadioInspector |
|---|---|
| «нет SCPI-драйверов для R&S/Keysight» | есть: `devices/scpi.py` (TCP + `Vxi11Instrument`), `devices/serial_scpi.py` (RS-232/USB) |
| «нет индексируемой СУБД панорам, только логи» | ядро — SQLite (`session_store.py`, `panorama.py`), выборка по частоте/времени/гео |
| «нужно добавить SCPI/VISA-драйвер» | уже реализовано |
| «нужно воспроизвести двухприёмную схему SoundScaner» | есть программный контур: `device_workers` + `automatic-handoff` на AR-DV1 (без ZeroMQ — через HTTP/SSE) |
| «оперируют относительными dBFS» | исходные **dBm** (tinySA) и `s_meter_count` (AR-DV1) без конверсии |

## 2. Реальные разрывы (валидная часть, с конкретикой)

| # | Разрыв | Состояние в OpenRadioInspector | Целевая спецификация / направление |
|---|---|---|---|
| 1 | **Метод разности панорам с антенным коммутатором** | отсутствует (математическое сравнение двух архивных свипов есть — `sweep_comparison.py`, но аппаратного коммутатора нет) | 4/8-канальный ВЧ-коммутатор 25 МГц–6/9 ГГц + НЧ-вход ≤30 МГц для проводных линий; опорная антенна «снаружи», поисковые «внутри», вычитание опорной панорамы в реальном времени. Программный аналог без железа — дифференциальное вычитание двух одновременных потоков (RT-Group Lite) |
| 2 | **Бинарный транспорт SCPI** | только ASCII-парсинг `CURVE`/`TRACE` | `FORMat REAL,32`/`INT,32` + IEEE 488.2 definite-length block (`#N...`) для панорам 10 000–600 000 точек и скорости >1 ГГц/с |
| 3 | **Цифровые декодеры (DTest-класс)** | `iq.py` — только калькулятор бюджета; записи IQ и демодуляторов нет | запись IQ в SigMF по триггеру детектора + открытые CLI-декодеры (`dsd-fme` для DMR/TETRA/P25, `rtl_433` для ISM-телеметрии) без нарушения MIT |
| 4 | **Интермодуляция 2/3/5/7 порядков** | `interference.py` покрывает гармоники и интермод 2-го/3-го порядка | добавить 5-й/7-й порядок и автоматическую проверку пиков по комбинационным частотам мощнейших несущих |
| 5 | **Огибающая адаптивного порога** | есть первый срез — локальная медиана + запас (`sweep_threshold.py`) | огибающая минимума графика максимумов оригинала не воспроизведена |
| 6 | **3D-спектрограмма** | отсутствует | низкий приоритет (способ отображения) |

## 3. Приоритет

Согласовано с независимым ревью ([`reviews/2026-11-09/README.md`](reviews/2026-11-09/README.md)):

1. Сначала — блокеры корректности/безопасности: аутентификация API, `units.dbmv`/`field_strength`, SCPI fail-closed, `detector_state` (write amplification), SSRF-валидация webhook, стабилизация тест-сьюта на Windows.
2. Затем — разрывы №1 (антенный коммутатор / программное дифференциальное сравнение) и №2 (бинарный SCPI) как максимально результативные для TSCM.
3. №3–№6 — по мере приоритетов из `rt-comparison.md`.
