# Расширенная проверка рабочего места macOS

Дата: 15 ноября 2026. Проверяется ветка `feat/operator-workbench`.
Это отчёт о проверенных сценариях, а не полная аппаратная или метрологическая приёмка.
Сырые измерения, локальные журналы и снимки рабочего стола в репозиторий не включены.
Прогон выполнен в рабочем дереве с ранее существовавшими локальными изменениями
вне этого среза. Они сохранены, но в коммит не включены; чистая CI-проверка
опубликованного коммита остаётся необходимой.

## Исправления по результатам проверки

- При минимальном окне 1000×700 pt строка вкладок могла занимать большую высоту,
  вытесняя нижнее управление за границы окна. Строка теперь сохраняет естественную
  высоту; лишняя видимая подпись picker убрана, accessibility-наименование сохранено.
- Длинные пересекающиеся линии от легенды к пикам заменены метками P1/P2/P3
  непосредственно возле точек. Ранжирование пиков и исходные уровни не изменены.
- Для тонких трасс 3D добавлен минимальный уровень яркости и немного увеличена
  толщина. Геометрия, исходные отсчёты и 2D-палитра не изменены.
- Добавлены проверки замены старой архивной страницы пустым результатом и
  повторного поиска после HTTP 503.

## Аппаратный стенд и границы проверки

macOS, Xcode Debug, tinySA Ultra ZS405, прошивка tinySA4_v1.4-235-gea71dfd.
Прибором владеет только служба ядра; интерфейс и проверки используют API.
Генератор не включался. Значение RBW подтверждается командой, физического
readback и измерения аналоговой полосы на этом стенде нет.

В начале расширенного прогона ранее оставленный сеанс уже показывал ошибку
синхронизации tinySA. Новый запуск ядра и соединения восстановил реальные
измерения. При повторном прогоне после 37 измерений снова возник таймаут
завершающего `ch>` в ответе scan. Worker остановлен с `restart_required=true`;
ожидавшая настройка стала unknown. UI сообщил «Применено 0/3. Соединение tinySA
изменилось», не выдав ложного успеха. Причина потери ответа не установлена;
длительная автономная работа без ошибок не подтверждена. Автоматические
повторные команды после потери синхронизации не добавлялись.
Новый stop/start также завершился таймаутом синхронизации до команды.
Для продолжения аппаратной части запрошен физический перезапуск прибора/USB;
состояние ошибки не называется LIVE.

## Автоматические проверки

- Xcode BuildProject: успешно.
- Библиотека: 311 XCTest (8 skipped), 22 Swift Testing — без ошибок.
- Приложение: 40 Swift Testing — без ошибок; полный XCTest имеет прежние ошибки
  Keychain/WebKit (три метода, шесть assertions), воспроизведённые ещё до этих
  исправлений. Проверка физического USB из unit-тестов исключена, чтобы не
  конкурировать с ядром за порт.
- 98 тестов архива, sweep-context, ёмкости, экспорта и структуры проекта: успешно.
  На macOS нужен `TMPDIR=/private/tmp`: путь через символьный `/var` отвергается
  проверкой безопасности собственного архива тестов.
- Приборный Python-набор: 330 тестов, 22 ошибки подготовки PTY
  (`OSError: out of pty devices`); остальные 308 без ошибок. PTY-проверки не
  засчитываются как успешные и не заменяются аппаратным тестом.
- Полный Python discovery: аварийное завершение 134. Диагностический повтор
  с `-X faulthandler -v` локализовал abort в `tkinter.Tk()` теста
  `FieldClientValidationTests.test_actual_tk_client_calculates_and_scope_change_clears_result`.
  У полного прогона нет итогового результата.
- Полный release runner: проверка зависимостей завершается с exit -6 при
  инициализации Tk. Это блокирует полную release-приёмку.

Команды воспроизведения (из соответствующего каталога):

```sh
# macos
swift test --disable-sandbox -Xswiftc -disable-sandbox --skip testPhysicalTinySAUltraSmokeIfConnected
# macos/SpektrKomandy
swift test --disable-sandbox -Xswiftc -disable-sandbox
# корень репозитория
TMPDIR=/private/tmp .venv/bin/python -m unittest discover -s tests -t .
.venv/bin/python -m tests.run_release_checks
```

## Не считать проверенным

AR-DV1, демодуляция и аудиотракт: приёмник отсутствует в текущем сеансе,
аудиовход ядра не настроен. Охрана: нет подготовленного проекта и операторских
подтверждений тракта; эти подтверждения автоматически не выставлялись.
Выбор RBW в popup отдельно от API, файловые диалоги профилей и оставшиеся
жесты интерфейса требуют отдельного подтверждения. VBW, IQ, расширенный RF-диапазон
и генератор не относятся к подтверждённым возможностям этого прогона.
