Папки, используемые по умолчанию программами 
RInspectorRC, RInspectorRT, RInspectorRP, RInspectorWiFi, I_MasterDevice. 

По умолчанию программное обеспечение RadioInspector для хранения настроек, 
файлов баз данных панорам, сохраненных аудиозаписей и временных файлов 
использует папку < RInspector>, которая находится в директории 
пользователя (там же, где находится папка "Мои документы"). 

Назначение поддиректорий в папке <RInspector>: 

<RInspector>-> <DataBase> -> <Range Control> - файлы панорам, полученные в режиме 
"Контроль диапазонов частот" ("Frequency range (f1-f2) scan and inspection") (*.pan) 
или "Контроль фиксированных частот" ("Discrete frequencies inspection") (*.fcs). 

<RInspector> -> <DataBase> -> <Direct Control> - файлы панорам, полученные в режиме 
"Экспертный анализ излучений, выполнение измерений" ("RF Signal analysis and performance measurement") 

<RInspector>-> <INIT> и <RInspector>-> <IWiFiInit> - файлы текущих настроек программ. 

<RInspector>-> <WAVE> - файлы сохраненных аудиозаписей. 

В остальных папках хранятся служебные данные. 
Как правило, папка <RInspector> легко доступна для пользователя с любыми привилегиями. 
Для изменения папки, используемой для хранения настроек, файлов баз данных панорам, 
сохраненных аудиозаписей и временных файлов необходимо в файле DefFoldersPath.txt 
указать путь к папке, которая будет использоваться для хранения настроек, файлов 
баз данных панорам, сохраненных аудиозаписей и временных файлов. 
Например: c:\RadioInspectorData\.Указанная папка должна существовать. 
Файл DefFoldersPath.txt находится в директории, куда установлено программное 
обеспечение RadioInspector.
