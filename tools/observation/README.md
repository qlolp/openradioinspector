# Сбор свидетельств интерфейса коммерческого оригинала

Инструменты наблюдения запущенной RadioInspector на машине, где она
установлена. Каталог `tools/analysis/` разбирает бинарники и базы; этот
каталог собирает то, что видно только в работающей программе: окна, снимки
экрана, дерево процессов, файлы данных и журналы.

## Что собирает `collect_original_ui.ps1`

| Раздел | Содержание |
|---|---|
| Окна | все видимые и скрытые окна: заголовок, класс, PID, процесс, координаты, размер — карта интерфейса |
| Процессы | путь, версия, описание продукта, время запуска, заголовок главного окна, загруженные модули |
| Снимки | PNG всех мониторов |
| Комплект | каталоги установки и перечень файлов с размерами |
| Данные | файлы `.pan`, `.fcs`, базы, конфиги; содержимое мелких текстовых конфигураций |
| Реестр | ключи правообладателя — только чтение |
| Журналы | хвост последних 400 строк каждого журнала |

Скрипт ничего не изменяет: нет записи в реестр, нет правки файлов оригинала,
нет управления программой. Всё, что он делает, — чтение.

## Запуск

```powershell
powershell -ExecutionPolicy Bypass -File tools\observation\collect_original_ui.ps1
```

Результат складывается в `%USERPROFILE%\Desktop\ori-observation\<метка>\`:
`windows.csv`, `manifest.json`, `report.txt`, `screens\*.png` и `text\*` с
выгрузками.

Полезные параметры:

```powershell
# другой каталог и более широкий фильтр процессов
powershell -ExecutionPolicy Bypass -File collect_original_ui.ps1 `
  -OutDir D:\ori -ProcessFilter "Inspector,RInspector"

# без снимков экрана, если они не нужны
powershell -ExecutionPolicy Bypass -File collect_original_ui.ps1 -NoScreenshots
```

## Что делать с результатом

1. Заархивировать каталог целиком и прислать в диалог — снимки и манифест
   дают карту интерфейса и фактическое состояние программы.
2. Снимки экрана коммерческой программы **не выкладываются** в публичный
   репозиторий. В репозиторий попадает только текстовое описание: названия
   окон, пункты меню, формулировки и порядок действий.
3. Разбор присылаемых материалов и сверка со справкой оформляются в
   [`docs/commercial-observation.md`](../../docs/commercial-observation.md) и в
   сравнении с оригиналом.

## Ограничения

* Скрипт не управляет программой: он не открывает панели и не нажимает
  кнопки. Для интерактивного обхода нужен Computer Use на стороне клиента
  либо сценарий `pywinauto`, запущенный вручную.
* Снимки отдельных окон не делаются: снимаются мониторы целиком. Панели
  оригинала, открытые поверх других окон, в такой снимок попадают.
* Списки модулей процесса и содержимое реестра могут требовать прав
  администратора; при отсутствии прав раздел помечается, сбор не прерывается.
