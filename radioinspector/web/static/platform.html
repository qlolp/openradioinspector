Автоматический handoff · по умолчанию выключен

Политика запрашивается у ядра…

Политика действует только в текущем процессе. После перезапуска требуется новое явное включение. Эта политика не обнаруживает кандидатов и не завершает исследования; обнаружение настраивается отдельно. Выключение политики не отменяет уже активное исследование.

Автоматическое завершение · по умолчанию выключено

Политика запрашивается у ядра…

Политика действует только в текущем процессе и не отменяет исследования при выключении. Завершаются только listening/decoding после минимального времени и нужного числа наблюдений receiver. Сохранение параметров не включает завершение.

Ручной handoff

Очередь пуста. Выберите кандидата и назначьте receiver.

Программный контур. Управление физическими приборами не заявляется: фактический признак hardware_control=…. Значения dBm и s_meter_count не смешиваются.
