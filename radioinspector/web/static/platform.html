Сравнение архивных свипов · Δ dB

Исходные трассы и водопад выше: dBm. Ниже: разность, рассчитанная ядром без изменения архива.

Опорный свип не закреплён.

Именованные опорные свипы · до 100 на сеанс

Хранилище каталога: ещё не проверено.

Сохранение только по кнопке. Прерывание ожидания или смена сеанса не отменяет запись на сервере; при неопределённом результате обновите каталог. Переименование, замена и удаление не выполняются.

Усреднённый опорный · средняя мощность

Ядро рассчитывает среднее арифметическое в линейной мощности с равными весами и возвращает dBm. По явной команде оно ищет непрерывные области прироста разности; это не автоматическое обнаружение кандидатов и не калибровка. Исходные измерения доступны только для чтения.

Нет dBm свипов выбранного потока.

Закрепление локальное: ровно N свипов перед последним dBm свипом в полученном окне выбранного потока. Нужно N+1 свипов, без автоматического уменьшения N. Это не постоянный именованный опорный. Новые свипы не меняют опорный или результат; изменение N и смена области или соединения очищают их. Изменение порога или ширины снимает только результат, сохраняя закреплённые источники. Сравнение только по кнопке, без записи и команд приборам.

Контекст архивного свипа · N1 / N2

Снимок ближайших архивных свипов того же потока до и после выбранного якоря. Порядок: начало UTC, затем точный ID (UTF-8). Автоматический захват N1/N2 при обнаружении не реализован. Нет привязки к кандидатам, записи или команд прибору.

Нет полученного архивного dBm свипа выбранного потока.

Начальные N1=2 и N2=2 — примеры. Новые свипы не меняют закреплённый якорь или результат; недостающие стороны показываются явно, без ожидания новых данных. Выбранный исходный свип сохраняется локально после ухода из полученного списка: повторная загрузка по кнопке проверит новое окно архива. Редактирование очищает результат; смена области и потеря соединения также сбрасывают сохранённый выбор. Выберите строку, чтобы увидеть все исходные точки её спектра в dBm на общей сетке частот, без интерполяции.

Якорь не закреплён.

Занятость окна — доля свипов с уровнем строго выше ручного порога (−80 dBm — пример). Это не доля времени работы передатчика. Разрывы архива не считаются отсутствием сигнала; интервалы сканирования не задают время наблюдения каждой частоты.


          
    
          
    
          
        
    
        
    
          
    Три горизонтальных порога архивного свипа · dBm
    
          
    Три независимые ручные линии, в любом порядке, в том числе одинаковые. Начальные −90, −80, −70 dBm — только примеры, не нормативные пределы. Это не автоматический детектор, не калибровка и не объединение с маской или адаптивным порогом.
    
          
    
            
            
            
          
    
          
    Нет архивного dBm свипа выбранного потока.
    
          
    
            
            
          
    
          
    Анализ только по кнопке. Новые свипы обновляют следующую цель, а результат сохраняет исходный свип, UTC, настройки и три введённых уровня. Редактирование очищает результат. Совпадающие линии различаются вложенными кольцами, исходный свип — малым квадратом.
    
          
    
          
    
          
          
    
          
      
          
      
          
        
          
        
          
          
        
          
        
          
          
          Адаптивный порог архивного свипа · dBm
          
          
          Ядро берёт локальную медиану центрированного окна, включая текущую точку; у краёв окно обрезается. Порог = медиана + запас dB. Это не калиброванный шум и не достоверность обнаружения.
          
          
          
            
            
          
          
          
          Нет архивного dBm свипа выбранного потока.
          
          
          
            
            
          
          
          
          Только чтение по кнопке: без записи, кандидатов и команд прибору. Новые свипы не меняют результат. Равенство порогу не считается превышением; области непрерывны по индексам, а не по расстоянию частот.
          
          
          
          
          
          
          
            
        
            
        
            
          
            Табличная спектральная маска · dBm
            
          
            Переносимый JSON: 2–128 вершин, целые Гц и пределы dBm. Ядро линейно интерполирует только пределы маски в dBm, без экстраполяции и изменения исходных измерений. Таблица не является подтверждением соответствия нормативам.
            
          
          
          
          
          
            Черновик не проверен ядром.
            
          
            Нет архивного dBm свипа выбранного потока.
            
          
            
            
            
            
            
          
            
          
            Импорт и редактирование локальны. Только кнопка анализа передаёт черновик выбранному ядру: без записи, кандидатов и команд прибору. Черновик сохраняется при смене области, но не применяется автоматически. Новые свипы не меняют зафиксированный результат. Равенство не превышение; области непрерывны по индексам.
            
          
            
          
            
          
          
              
        
              
        
              
          
              Округление частоты обнаруженных сигналов · таблица сетки
              
          
              Переносимый JSON: 1–64 записей «диапазон + шаг сетки». Ядро округляет центральные частоты выбранных кандидатов до ближайшей точки сетки своей записи; при равном расстоянии берётся более высокая точка. Исходные частоты архива не изменяются. Частоты вне всех записей не округляются.
              
          
          
          
          
          
          
          
              Черновик не проверен ядром.
              
          
              Нет кандидатов выбранного сеанса.
              
          
              
            
            
            
            
          
              
          
              Импорт и редактирование локальны. Только кнопка округления передаёт черновик ядру: без записи, изменения кандидатов и команд прибору. Сетка записи — точки start_hz + k·grid_step_hz внутри диапазона. Это не калибровка и не сверка с нормативной сеткой каналов.
              
          
              
          
              
          
                
        
                
        
                
          
                Результаты измерений с явной методикой
                
          
                Каждый результат несёт методику, код результата (норма / не норма / не выполнено) и числовые значения отдельно — как таблицы *_RESULT и *_RESULTCODE оригинала. Запись привязана к сеансу, потоку прибора и интервалу UTC. Это производная запись: исходные измерения архива не изменяются.
                
          
          
          
                
            
            
            
            
          
                
          
          
          
                Нет выбранного сеанса.
                
          
                
            
            
            
          
                
          
                Только явное действие записывает результат. Методика определяется явно, а не выводится из формата хранения. Код результата не подменяет значения и не является нормативным заключением.
                
          
                
          
                
          
                  
        
                  
        
                  
          
                  Встроенный частотомер · измерение частоты с погрешностью
                  
          
                  Измерение частоты пика архивного dBm свипа в заданном окне. При равномерной сетке и пике внутри окна применяется параболическая интерполяция трёх бинов; иначе измеряется сам бин пика. Погрешность — честная граница max(разрешение, сетка)/2: оценка не лучше разрешения прибора и записанного растра. Это производная оценка по записанным данным, не показание аппаратного счётчика.
                  
          
          
          
                  
            
            
            
          
                  
          
                  Нет архивных dBm свипов выбранного потока.
                  
          
                  
            
            
          
                  
          
                  Только чтение по кнопке: без записи, кандидатов и команд прибору. Исходные бины свипа не изменяются. Значения результата готовы для записи через «Результаты измерений» с методикой frequency_counter. Это не аттестованное средство измерений.
                  
          
                  
          
                  
          
                    
        
                    
        
                    
          
                    Параметры DVB-T · сверка с пороговыми значениями
                    
          
                    MER, BER после Витерби и после Рида — Соломона, защитный интервал и скорость кодирования. Ядро сравнивает введённые значения с пороговыми («Пороговые значения параметров DVB-T» оригинала) и возвращает код результата и вердикт по каждому параметру. Это оценка введённых чисел, а не измерение: демодуляция IQ и измерение MER/BER прибором не выполняются.
                    
          
                    
            
            
            
          
                    
          
                    
            
            
            
          
                    
          
                    
            
            
          
                    
          
                    Нет выбранного сеанса.
                    
          
                    
            
            
          
                    
          
                    Только явное действие выполняет оценку; архив не изменяется. Равенство порогу считается нормой (MER ≥ порога, BER ≤ порога). Код результата — признак по введённым числам, не нормативное заключение и не аттестация. Значения готовы для записи через «Результаты измерений» с методикой dvb_t_parameters.
