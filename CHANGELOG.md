# Changelog

## Кандидат 0.4.0 для macOS, Raspberry Pi и Windows

- Пульт показывает спектр, водопад, фактическое покрытие и давность обзора. Из события можно открыть исходный свип и проверить связанное наблюдение AR-DV1. Сохранённые повторы раздельно показывают, сколько раз повторились сигнал и расхождение приборов.
- Для сетки с шагом 10 кГц ядро хранит границы и исходные значения каждого окна. Охрана использует эталоны совместимых окон подтверждённого диапазона. Верхние окна сохраняются вместе с отметкой о необходимости аппаратной проверки.
- При записи новых панорам компактный архив v7 сохраняет исходные ID, UTC, частоты и уровни. Для отката доступен экспорт в отдельный архив v6.
- Пакеты включают русскую офлайн-инструкцию с иллюстрациями работающей программы. Для загрузки пакета и проверки доверенного издателя предусмотрена ведомость контрольных сумм. [Руководство](docs/operator-guide/index.html) · [Замеры и состояние выпуска](docs/release/status.md)
