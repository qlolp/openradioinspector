# Changelog

## 0.4.0.dev0 — не опубликован

- Наблюдение работающей RInspectorRT (RadioInspector Light 32314, v10.0.2 / 2020.03.18):
  инвентарь возможностей по интерфейсу со снимками экрана —
  docs/rinspectorrt-light-runtime-inventory.md.
- Третий сеанс наблюдения: работа с подключённым приёмником AOR AR-DV1
  (COM3, 115200, firmware 2504A) — живое измерение диапазона, перенос курсора
  в спектр по выбранному найденному сигналу, контекстные меню спектра и списка
  найденных сигналов, состояние баз и ограничения (Firebird, неверные часы
  приёмника).
- Интеграционная база #87 с заданиями, отчётами, аналитикой, архивом и тремя клиентами.
- tinySA prompt framing из #89, синтетический cross-platform runner из #90.
- Исправления единиц, RTL-TCP, статистики, сохранности архива, конкурентного доступа и UI-контекста.
- Управляемое локальное ядро и сценарии поставки Windows/macOS/Pi; аппаратная приёмка и установщики ещё проверяются.
- Коммерческий дистрибутив исключён из рабочего дерева. Очистка публичной истории не завершена.
- Сверка с RadioInspectorRT по документации и первичным артефактам: запись
  исследования, сопоставление по 33 блокам, решение по коммерческому диску.

Миграции архивов не выполняются скрытно. Перед обновлением остановить запись
и сохранить закрытую резервную копию каталога данных. При откате использовать
совместимую версию вместе с её резервной копией; не открывать архив старым
ядром, если его версия формата не поддерживается.
